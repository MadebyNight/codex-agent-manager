# v0.1.1-rc.1 · Orca 共用角色文件修复测试版

此预发布版用于在曾出现“引用了配置目录之外的文件”的电脑上复测。正式版仍为 v0.1.0。

## 修复

- 识别 Orca 角色引用所选原生 Codex 配置目录中的文件；此类引用不再阻止新增其他子代理。
- “同时修改两套”时，共用文件只写入和备份一次，并保留预览、冲突检查与恢复。
- 单独编辑共用角色时提示切换到“同时修改两套”；其他目录外引用仍被拒绝。

## 测试步骤

1. 下载并完整解压 `codex-agent-manager-v0.1.1-rc.1-windows-x64.zip`，保留 `_internal` 文件夹。
2. 在原生与 Orca 均启用的情况下，确认页面不再显示三个官方角色的目录外引用报错。
3. 选择“同时修改两套”，新增一个自定义角色并确认预览、模型测试与保存正常。
4. 编辑一个共用的官方角色，确认预览只列出一份角色文件；保存后检查两套角色显示。

测试前请停止旧版面板。新版可以解压到另一目录运行；原 `.local` 设置和备份请保留，不要随软件包分享。实际 Orca 同步行为仍需在报错电脑上验证。

附件 `SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。
