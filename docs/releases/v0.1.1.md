# v0.1.1 · Windows 便携版

## 更新

- 修复 Orca 与原生 Codex 共用角色文件时的识别和写入：新增其他角色不再被共享引用阻止；同时修改两套时共享文件只处理一次。
- 首次选择配置目录后，从当前服务商的 `GET /models` 接口读取可选模型。服务商提供 `supported_reasoning_levels` 时，推理强度按模型显示。
- 模型列表请求失败时显示原因，并保留手动输入模型 ID 和已有配置模型的选择方式。

## 下载与验证

下载 `codex-agent-manager-v0.1.1-windows-x64.zip` 并完整解压，保留 `_internal` 文件夹。更新前先停止旧版面板，保留原有 `.local` 设置和备份。

已使用临时配置和本地模拟服务完成单元测试、浏览器验收及便携包启动测试。模型列表接口只用于提供选择；保存角色前仍需通过实际 Responses 连通性测试。标准 Models API 不提供推理强度时，面板显示通用选项。

附件 `SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。
