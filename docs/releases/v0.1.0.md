# v0.1.0 · Windows 免安装便携版

用本地 Web 面板管理原生 Codex 和 Orca 托管 Codex 的子代理，无需启动 Agent 会话来编辑配置。

## 下载与使用

1. 下载附件 **codex-agent-manager-v0.1.0-windows-x64.zip**（不要下载 Source code）。
2. 完整解压到可写目录，双击 **CodexAgentManager.exe**，保留同目录的 `_internal` 文件夹。
3. 在浏览器中确认两套 Codex 配置目录；未安装的一套取消启用。
4. 选择角色与模型，预览变更，连接测试通过后保存。

内置 Python 及运行依赖，无需额外安装 Python / Node.js。支持 Windows 10/11 x64。首次启动面板可离线进行，实际模型连接测试需要网络并产生少量 API 用量。

## 功能

- 原生 Codex / Orca / 两套同时修改。
- 点击直接展开模型列表、输入筛选、任意自定义模型 ID。
- 新增、编辑、删除自定义角色；官方角色仅 GPT，可恢复默认。
- 配置目录自动检测、文件夹选择、路径记忆，允许仅启用一种工具。
- 变更预览、自动备份、冲突检测、双套失败回滚及最近一次恢复。

## 验证与范围

- 自动化测试覆盖配置读写、路径选择、隔离、回滚、连接测试和浏览器操作。
- 实际 ZIP 解压后以 PATH 不含 Python / Node.js 的环境验证 EXE 启动、静态资源、设置记忆、模型请求、配置保存及退出。
- 仅支持已有 API Key 的 Responses 兼容服务商，不代办 ChatGPT OAuth 登录。
- 已按 Codex 0.155.1 核查；不自动扫描项目级配置、WSL 或所有 Orca 账号。
- 这是社区工具，非 OpenAI 或 Orca 官方产品。

关闭浏览器不会停止后台；双击“停止面板.cmd”退出。设置与备份保存在解压目录 `.local`，更新时请保留，分享软件时请排除。

附件 **SHA256SUMS.txt** 提供 ZIP 的 SHA-256 校验值。
